## 🌐 About

A personal portfolio website built to showcase my work as a Unity Game Developer — and used as a playground to experiment with **Three.js** for interactive, web-based 3D experiences. Building this helped me sharpen my skills in 3D graphics on the web and dynamic JavaScript-driven UI, outside of the Unity engine.

**🔗 Live site:** [anvarms.github.io/Portfolio](https://anvarms.github.io/Portfolio/)

<br/>

## ✨ Pages

| Page | Description |
|---|---|
| 🏠 `index.html` | Landing page with interactive Three.js elements |
| 👤 `about.html` | Background, skills, and journey into game development |
| 💼 `experience.html` | Professional experience and work history |
| 🎮 `games.html` | Showcase of shipped and prototype game projects |
| 📄 `resume.html` | Resume viewer with direct download |
| ✉️ `contact.html` | Contact details and links to reach out |

## 🚀 Running Locally

```bash
git clone https://github.com/AnvarMs/Portfolio.git
cd Portfolio
```

Then just open `index.html` in your browser — no build step required, it's a static site. For live-reload while editing, you can serve it with any local server, e.g.:

```bash
npx serve .
```
